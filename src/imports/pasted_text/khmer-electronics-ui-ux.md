Design a complete, modern, clean, professional, and responsive **Khmer Electronics E-Commerce Website UI/UX in Figma**.

The website is an online electronics store in Cambodia selling computers, laptops, smartphones, tablets, computer accessories, components, and other electronic devices.

IMPORTANT LANGUAGE REQUIREMENT:

* All visible website UI text MUST be written in natural Khmer language.
* Do NOT use English for navigation menus, buttons, headings, forms, filters, product status, checkout labels, or customer dashboard labels.
* English may only appear where necessary for brand names, model names, technical specifications, RAM, SSD, CPU, GPU, Wi-Fi, etc.
* Use natural Khmer suitable for a real Cambodian online store.
* Do not use machine-like or unnatural Khmer translations.

IMPORTANT:
Focus ONLY on UI/UX design.
Do NOT generate Laravel, database, API, or backend code.

## 1. Typography

Use **Noto Sans Khmer** as the main UI font.

Typography:

* Main Heading: Noto Sans Khmer Bold
* Section Heading: Noto Sans Khmer SemiBold
* Body: Noto Sans Khmer Regular
* Button: Noto Sans Khmer Medium
* Small Text: Noto Sans Khmer Regular

Make Khmer text comfortable to read with sufficient line height and spacing.

## 30. Prototype Flow

Connect:

ទំព័រដើម → ហាងទំនិញ

ទំព័រដើម → ព័ត៌មានលម្អិតទំនិញ

ព័ត៌មានលម្អិតទំនិញ → កន្ត្រកទំនិញ

កន្ត្រកទំនិញ → បំពេញការបញ្ជាទិញ

បំពេញការបញ្ជាទិញ → ការបញ្ជាទិញជោគជ័យ

ចូលគណនី → គណនីរបស់ខ្ញុំ

គណនីរបស់ខ្ញុំ → ការបញ្ជាទិញរបស់ខ្ញុំ

ការបញ្ជាទិញ → ព័ត៌មានការបញ្ជាទិញ

ហាងទំនិញ → ព័ត៌មានលម្អិតទំនិញ

## FINAL REQUIREMENTS

The final design must feel like a real Cambodian electronics e-commerce platform.

Prioritize:

1. Clean UI
2. Easy navigation
3. Natural Khmer language
4. Modern electronics-store appearance
5. Clear product information
6. Easy shopping and checkout
7. Responsive design
8. Consistent design system
9. Professional product cards
10. Excellent readability of Khmer text

Use Noto Sans Khmer consistently.

Do not translate actual international brand names or technical product model names into Khmer.

The UI should be ready for later development using React.js, Tailwind CSS, Laravel REST API, and MySQL.
